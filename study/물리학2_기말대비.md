## 2. 챕터별 핵심 (Ch.28~36)

### Ch.28 자기장 (복습, 기말 범위 아님, 과제3 연동)
- F = qv×B, 원운동 반지름 r = mv/(qB), 주기 T = 2πm/(qB)(속력과 무관, 사이클로트론)
- 홀 효과: 띠에서 전하운반자가 한쪽에 쌓여 전위차 V 발생, 극성으로 운반자의 부호를 판단
- 전류 도선에 작용하는 힘 F = iL×B, 코일의 토크 τ = μ×B, 에너지 U = −μ·B (μ = NiA)

### Ch.29 전류가 만드는 자기장 (과제3 연동)
- 비오-사바르: dB = (μ₀/4π) i ds×r̂/r². 무한 직선 B = μ₀i/(2πR), 원호 중심 B = μ₀iφ/(4πR)
- 평행 전류 사이의 힘(같은 방향은 인력), 앙페르 법칙 ∮B·ds = μ₀i_enc
- 솔레노이드 B = μ₀in, 토로이드 B = μ₀iN/(2πr), 자기쌍극자 축 위 B = μ₀μ/(2πz³)

### Ch.30 유도·인덕턴스 (과제3 연동)
- Φ_B = ∫B·dA, 패러데이 ε = −N dΦ_B/dt, **렌츠 법칙**(유도전류의 자기장은 자속 변화를 방해)
- 유도 전기장: ∮E·ds = −dΦ_B/dt (솔레노이드 안쪽 E ∝ r, 바깥쪽 E ∝ 1/r)
- 인덕턴스 L = NΦ_B/i, 솔레노이드 L/ℓ = μ₀n²A, RL 회로 τ_L = L/R, 자기에너지 U_B = ½Li², u_B = B²/(2μ₀), 상호유도

### Ch.31 전자기 진동과 교류 ★기말 범위
- LC: U_E = q²/2C, U_B = Li²/2, ω = 1/√(LC). 감쇠 RLC: q = Qe^(−Rt/2L) cos(ω′t+φ)
- 직렬 RLC 교류: I = ε_m/√(R² + (X_L − X_C)²), tan φ = (X_L − X_C)/R, X_L = ω_d L, X_C = 1/(ω_d C), 공명 ω = 1/√(LC)
- 평균 전력 P_avg = I_rms²R = ε_rms I_rms cos φ
- 변압기: V_s = V_p N_s/N_p, I_s = I_p N_p/N_s, 등가저항 R_eq = (N_p/N_s)²R

### Ch.32 맥스웰 방정식 ★
- 자기장의 가우스 법칙 ∮B·dA = 0 (자기홀극 없음)
- **변위전류** i_d = ε₀ dΦ_E/dt, 앙페르–맥스웰 법칙 ∮B·ds = μ₀ ε₀ dΦ_E/dt + μ₀ i_enc
- 맥스웰 방정식 네 개: 전기 가우스, 자기 가우스, 패러데이, 앙페르–맥스웰
- 스핀·궤도 자기모멘트, 보어 마그네톤 μ_B = 9.27×10⁻²⁴ J/T, 반자성/상자성/강자성(자화, 포화, 퀴리온도)

### Ch.33 전자기파 ★
- E = E_m sin(kx−ωt), B = B_m sin(kx−ωt), c = 1/√(μ₀ε₀) = E/B
- 포인팅 벡터 S = E×B/μ₀, 세기 I = E_rms²/(cμ₀), 점광원 I = P_s/(4πr²)
- 복사압: 완전 흡수 p_r = I/c, 완전 반사 p_r = 2I/c (힘은 압력×면적)
- 편광: 비편광→편광판 I = I₀/2, 편광→ **I = I₀cos²θ**(말루스)
- 반사·굴절: 스넬 n₂sinθ₂ = n₁sinθ₁, 전반사 임계각 θ_c = sin⁻¹(n₂/n₁), 브루스터각 θ_B = tan⁻¹(n₂/n₁)

### Ch.34 상(image) ★
- 구면 거울: 1/p + 1/i = 1/f = 2/r. 구면 굴절면: n₁/p + n₂/i = (n₂−n₁)/r
- 얇은 렌즈: 1/p + 1/i = 1/f = (n−1)(1/r₁ − 1/r₂)
- 실상 vs 허상, 광학기기: 돋보기 m_θ = 25cm/f, 현미경, 망원경 m_θ = −f_ob/f_ey
- 부호 규약(p, i, f, r)을 먼저 정리해 두는 게 가장 중요해요

### Ch.35 간섭 ★
- 하위헌스 원리, 매질 속 파장 λ_n = λ/n
- 영의 이중슬릿: 밝은 무늬 d sinθ = mλ, 어두운 무늬 d sinθ = (m+½)λ, 세기 I = 4I₀cos²(φ/2), φ = (2πd/λ) sinθ
- 결맞음(같은 파장, 일정한 위상차)
- **박막 간섭** (공기 속 막): 밝음 2L = (m+½)λ/n₂, 어두움 2L = mλ/n₂ (반사 위상 변화에 유의, 슬라이드 조건을 그대로 확인할 것)
- 마이컬슨 간섭계: 한쪽 경로를 바꾸면 무늬가 이동, 무늬 수 N = 2Δ(경로)/λ

### Ch.36 회절 ★ (진행 중)
- 단일 슬릿 극소: a sinθ = mλ (m = 1, 2, …), 첫 극소 sinθ = λ/a, 슬릿이 넓을수록 중앙 극대가 좁아짐
- 원형 구멍 첫 극소: sinθ = 1.22λ/d, 레일리 기준(분해능 한계)
- (아직 안 나온 부분: 이중슬릿 회절, 회절격자, X선 회절 — 과제 4에 들어 있으니 교재 읽기)
