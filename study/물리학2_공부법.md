## 3. 공부 방법

1. **각 챕터를 "유도 목록"으로 만들어 백지에서 다시 쓰기.** 시험에 나올 만한 건 결과 암기가 아니라 유도예요.
   - 고리 → 원판 (적분으로 쌓기), 가우스 법칙으로 구·원통·평면, 평행판·원통·구 전기용량, RC 회로의 미분방정식 풀이
   - 각 유도마다 **극한 검사**를 습관으로: z ≫ R이면 점전하처럼 되는가, R → ∞이면 평면 결과가 되는가
2. **"어떤 도구를 쓸까" 판단 표 만들기.**
   - 대칭이 있다 → 가우스 법칙. 대칭이 없다 → 쿨롱 적분 또는 중첩
   - 전하 분포가 연속 → dq를 잡고 적분. 스칼라(전위)가 벡터(전기장)보다 쉬우면 V부터 구한 뒤 E = −∇V
   - 도체가 나오면: 내부 E = 0, 표면은 등전위, 전하는 표면에만, 공동 안 전하의 유도전하
3. **벡터 방향을 먼저 그림으로.** 고리·선 문제는 어떤 성분이 소거되는지를 먼저 그리고 시작하면 적분이 절반으로 줄어요.
4. **강의안 Checkpoint를 직접 풀기.** 강의안에 Checkpoint 문제가 있어요 (예: Ch.21 #2·#4, Ch.22 #1, Ch.24 #3, Ch.25 #2, Ch.26 #4, Ch.27 #2·#4, Ch.28 #1). 정답이 슬라이드에 같이 있으니 가리고 풀고 확인하세요.
5. **교재 연습문제** 챕터 끝 문제를 챕터당 5~8개 (쉬운 것 → 응용 순서). 중첩·적분형 문제 위주로.
6. **단위와 크기 감각.** C, V, F, A, Ω의 관계, 전자의 표류속도(~10⁻⁵~10⁻⁴ m/s)와 열운동 속도(~10⁶ m/s)처럼 강의안에 나온 숫자는 개념 질문의 단골이에요.

## 4. 과제가 시험 대비가 되는 이유와 활용법

과제 문제 유형을 정리하면 시험에서 다시 만날 패턴이 보여요. 풀이를 대신 적지는 않고 접근 방식만 적어요.

**HW1 (Ch.21~23 범위)**
- 정사각형 모서리 점전하 → 벡터 중첩 연습 (성분으로 나눠서)
- 두 전하구가 실에 매달린 계 → 평형 조건 + 작은 진동. 교재 Ch.15 진자 참고, 대칭/반대칭 정상모드
- 막대의 쿨롱 힘 → dq 적분, 두 막대 사이 힘은 대칭으로 한 성분 소거
- 쌍극자·사중극자 먼 거리 근사 → 멱급수 전개 (거리 r에 대한 감소율 비교)
- 구멍 뚫린 평면 → 원판 결과의 중첩 (전체 − 구멍)
- 도체판 4장의 전하 재분포 → 도체 안 E = 0 + 바깥 E = 0 힌트, 전선으로 연결하면 전위가 같아짐
- 점전하 + 균일 구름 → 가우스 법칙, E-r 그래프 스케치
- 접지된 도체 평면 위 전자 → 영상전하법
- 편심 구·구멍 → 두 균일 분포의 **중첩 (구멍 = 반대 부호 전하)**, 결과가 일정한 전기장이 됨

**HW2 (Ch.24~27 범위) — 10/12 마감, 지금 풀 차례**
- 1차원 이온 사슬(Madelung) → 교번급수 + ln(1+x) 급수
- 양성자 빔 + 위치 모니터 → 원통 대칭 가우스 + 전위차를 로그로, δ ≪ a에서 선형화
- 쌍극자 일 → 전위 근사 vs 정확한 값 비교, **보존력이라 경로 무관**인지 확인
- 유전체 블록 배치 → 병렬/직렬 분해로 C를 x, t의 함수로 놓고 최대·최소
- 충전된 축전기를 충전 안 된 축전기와 연결 → 전하 보존, **에너지는 보존되지 않음**
- 적층 축전기(N장) → 인접 쌍은 병렬, 쌍의 개수 = N − 1
- 송전 손실 → P_loss = I²R에 I = P/V를 넣고 전압 의존성 비교
- 동축 케이블 절연층 → 축방향 저항(R = ρL/A) vs 반지름 방향 저항 (미소 껍질을 직렬로 적분)
- 연결선 저항 있는 축전기 공유 → 직렬 합성 C_s로 시간상수가 RC_s
- 두 전지 회로 → 키르히호프 + 각 저항 전력, 전원이 공급한 전력과 일치하는지 검산

**HW 활용:** HW1·HW2의 모든 문제를 **풀이를 가리고 시험 시간처럼 다시 풀어보기**. 막히는 문제가 시험 약점이에요. HW1은 채점 결과가 나오면 틀린 부분을 따로 모으세요.
